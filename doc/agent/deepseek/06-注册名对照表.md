## 六、本次检索的口径说明

- 检索到 66 处含模块前缀（`bhr_`/`rdt_`/`wi_`/`dev_`/`lgc_`）的 id 字面量；另有若干 id **不含前缀**（`mineral_soil*`、`rock*`、`slate`、`static_cobblestone`、`packed_planks`、`gem_*`、`crystallized_honey`、`blockheads_icon`），即上表需要改名或标 `#waiting2check` 的部分。
- 集合类（`BHR_Rocks`/`BHR_Soils`/`BHR_Gems`/`BHR__NormalBlocks`/`ModBlocks`）通过 `registerBlocks(...)` 辅助方法注册，因此**按 `Registry.register` 调用点计数会低估实际方块数**；本表按代码字段逐一枚举。
- 方块状态属性名（`bhr_decayed`、`grass_cover`、`dev_boolean`、`dev_int`、`dev_enum`、`dev_boolean_parallel`）不是注册名，本表不列。
- 枚举值（`dev_in`/`dev_out`/`dev_def`）不是注册名。

## 七、显示名与注册名分离（约定）

**2026-10-06 决定**：`bhr_gem_amethyst` 的**显示名**改为 **`Kunzite` / 紫锂辉**（原为 `Amethyst` / 三方紫晶）。

**理由**：原版已有 `amethyst`（紫水晶），英文显示名与之撞名；而五种宝石中 `emerald`→`Canutillos`、`diamond`→`'Adamant'` 早已规避原版名，此项属补齐一致性。

**注册名、类名、资源名一律不改**：`bhr_gem_amethyst`、`BHR_GemAmethyst`、`bhr_gem_amethyst.json`、`bhr_gem_amethyst.bbmodel`、贴图路径等**全部保持原名**。
原因：这些名字是为**致敬《The Blockheads》**而设定的，改动会失去致敬意义。

**实际改动范围（仅 7 处，已完成）**：

| 文件 | 处数 | 内容 |
| --- | --- | --- |
| `assets/richards-whimsy-mod/lang/zh_cn.json` | 3 | 方块名、方块物品名、宝石祝福提示 → `紫锂辉` |
| `assets/richards-whimsy-mod/lang/en_us.json` | 3 | 同上 → `Kunzite` |
| `src/main/java/.../item/ModItems.java` | 1 | 第 19 行注释内的中文名 |

**不要跟着改**：方块声音组 `SMALL_AMETHYST_BUD` 是引用原版音效，与命名无关。

**据此推导**：本文档各表中的注册名（`bhr_gem_amethyst` 等）**继续有效**；只有「中文显示名」需读作「紫锂辉」。

**已同步（2026-10-06，选项 A）**：中文显示名已统一改为「紫锂辉」——`doc/wiki` 内 **14 处**改名 + 本账本 **1 处**（第 55 行），另在 `BHR_GemAmethyst` 与 `BHR_GemBlessing` 各新增 1 行「致敬《The Blockheads》」说明。**注册名、类名、资源名一律不变。**
保留「三方紫晶」字样的只剩两处**历史性表述**，属有意为之：本页第 128 行（记录改名前后）、`BHR_GemAmethyst.md` 备注（记录显示名变更）。
