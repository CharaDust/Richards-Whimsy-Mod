## 2. 实现要点（与 11 号报告的对应）

### 2.1 方块类只做「转发」

| 覆写点 | 做什么 |
| --- | --- |
| `onPlace` | 服务端：`RDT_SpectreLensIndex.onLensPlaced` + `scheduleTick(pos, this, 80)` |
| `tick(BlockState, ServerLevel, BlockPos, RandomSource)` | `onLensClock` + 重排 80 tick |
| `neighborChanged` | 服务端：`onLensClock`（下方信标被换掉时立即修正） |
| `affectNeighborsAfterRemoval` | `onLensRemoved`（拆镜片 → 删记录） |
| `getShape` | 1/16 薄层（`Shapes.box(0,0,0,1,0.0625,1)`；`getCollisionShape` 默认取 `getShape`） |
| `getShadeBrightness` / `propagatesSkylightDown` | 补回父级玻璃的类行为（`ofFullCopy` 只复制属性，不复制类行为）；顺带让 `lightDampening = 0`，**镜片不挡信标光束** |

### 2.2 索引类（`RDT_SpectreLensIndex`）

- 结构（用户指定）：
  `Map<维度, Map<效果, Map<强度等级(1/2), Set<坐标>>>>` + 反查表 `Map<维度, Map<坐标, Set<RecordKey>>>`
- 效果键用 `ResourceKey<MobEffect>`（`Holder.Reference` 没覆写 `equals/hashCode`）；
- 强度等级：I = amplifier 0；II = amplifier 1（4 级信标且主副效果相同）；
- 读信标：
  - 级别：**自己数金字塔**（`BlockTags.BEACON_BASE_BLOCKS`，1~4 层）——不读 NBT 的 `Levels`（11 号报告 §4.3 的时序陷阱）；
  - 效果：`beacon.saveWithoutMetadata(...)` → `TagValueInput` → `primary_effect` / `secondary_effect`；
  - 光束：`getBeamSections()` 快路径；为空时做确定性回退扫描（金字塔 + 扫 `lightDampening >= 15` 的遮挡）；
  - 相邻区块没加载 → `Optional.empty()` = **无法判定，保留旧记录**（绝不误删）。
- 全局 80 拍（`END_LEVEL_TICK`，`gameTime % 80 == 0`）：
  1. 校验：区块未加载跳过；不是镜片 → 删；否则 `align`（与当前应有的记录对齐 = 删旧 + 写新，D2）；
  2. 施放：按 (效果, 强度) 节点给该维度所有玩家 `new MobEffectInstance(holder, 340, amp, true, true)`。
- `SERVER_STOPPED` 清空索引。

### 2.3 与决策的对应

| 决策 | 落地位置 |
| --- | --- |
| D1 等级 = amplifier+1 | `readRecords` 里 `doublePrimary ? 2 : 1`；施放 `amplifier = level - 1` |
| D2 换效果 = 删旧 + 当拍补新 | `align`（镜片自报与全局校验都走它） |
| D3 光束被挡算失效 | `isBeamBlocked` + `getBeamSections()` 快路径 |
| D4 第一期不落盘 | 索引只在内存；`SERVER_STOPPED` 清空；计划刻随区块存档自动重建 |
| D5 正下方一格 | `readRecords` 用 `lensPos.below()` |
| D6 数组即去重、按节点施加一次 | `applyEffects` 按 (效果, 强度) 节点施加；空数组 = 跳过 |

## 4. 已知限制（照实写）

1. **记录不落盘**（D4）：服务器重启后，区块未加载的镜片暂时不广播；区块加载后 ≤4 秒恢复。
2. **镜片自身不 tick 的区块**：区块加载但不在 ticking 范围时计划刻不跑，记录保留（符合「查询失败保留」）。
3. 信标金字塔变化不会通知镜片（不相邻），失效最迟在下一拍（4 秒）被发现。
4. 每个镜片每 4 秒做 164 次 `getBlockState`（数金字塔）+ 一次 NBT 快照；镜片很多时可考虑缓存，但目前不优化。
5. 挖掉镜片**没有掉落物**（战利品表全项目暂缓，登记点⑦）。
