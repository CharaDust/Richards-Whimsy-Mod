## 程序结构与迁移关注点

- `RichardsWhimsyMod.java` 的 `onInitialize()` 显式调用各主题的注册/初始化方法（约第 64-133 行）；功能模块不是由统一的自动扫描器发现。
- `RichardsWhimsyModClient.java` 的 `onInitializeClient()` 调用各主题客户端渲染初始化（第 13-29 行）。客户端渲染迁移可从这里追踪注册入口。
- `RichardsWhimsyModDataGenerator.java` 实现 Fabric `DataGeneratorEntrypoint`；相关 Provider 位于 `src/main/java/com/rcdmake/whimsy/datagen/`。
- 主要功能面包括方块与物品注册、方块实体、物品栏、状态效果、NBT/物品数据、Mixin、配方、ScreenHandler/界面、数据生成与客户端渲染。代表性实现：`block/ModBlocks.java`、`item/ModItems.java`、`recipe/ClassDEV/DEV_SimpleWorker_R.java`、`screen/ClassDEV/`、`function/ClassDEV/Render/`。
- 渲染代码包含 `GL11`/`RenderSystem` 使用；搜索证据可复现：`rg -n "GL11|RenderSystem|MatrixStack|RenderLayer|BlockRenderLayerMap" src/main/java`。
- Mixin 配置列出 3 个 Mixin，`compatibilityLevel` 为 `JAVA_17`：`src/main/resources/richards-whimsy-mod.mixins.json:1-13`。Mixin 注入点需要随目标游戏字节码和映射重新核验，不能只靠全局文本替换。
- 仓库含 209 个 JSON 资源文件，升级不只是 Java 编译问题；需检查 `pack.mcmeta`、数据目录名、配方/战利品格式、模型和 blockstate 资源。

以上条目描述仓库现状和搜索到的 API 使用，不等同于已证明这些 API 在 26.2 中被移除或如何替代。
