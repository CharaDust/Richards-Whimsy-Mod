## 协作约定

- GPT 生成的说明与描述文件放在 `doc/agent/gpt/`。
- 不修改其他 AI 品牌目录中的文件，也不把它们的判断未经复核地当作事实。
- 不以本目录文档替代项目正式文档；用户确认前，面向用户的文案草稿留在本目录。
- 文档中的版本建议与外部资料需注明来源及核实状态；仓库可直接验证的内容给出文件路径和行号。
