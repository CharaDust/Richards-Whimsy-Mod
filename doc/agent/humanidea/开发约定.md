- 为了防止牵一发而动全身，本模组内除非特殊要求（如一种方块的不同颜色），所有单独的方块，物品均写进一个独立的 Java 类中。每一个 Java 类均由相似的骨架构成，包括构造函数和初始化函数。在主类注册方块或物品的时侯，还有将方块及物品添加进创造模式物品栏的时候，只需要写一条初始化函数。详情请见javaref
- 大多数的方块都有其物品形式，方块物品的注册函数需要放在对应的方块内，而不是新建一个物品来单独注册。
- 本模组具有多个模块，每一个模块的内容除非特殊约定，应当保持独立，功能不能交叉。
- 存在于旧版本的类在wiki中标为了`#wait4move`，若wiki中带有此标记，代表需要从旧项目迁移，不带标记则表示迁移已完成
- 方块类的「蓝图叠层」定稿为 V1：见 `doc/wiki/example/blockv1.md`（配套样板 `src/main/java/com/rcdmake/whimsy/block/paradigm/ParadigmBlockV1.java`，不注册不参与编译）。要点：按 Minecraft 运行时顺序排列（属性工厂在构造器之前）；分层决定摆在哪、能力阶梯决定用什么手段；可选项显式标注；停在第 N 级要写明为什么没停在第 N-1 级
