# 喂食箱子（方块）
{`bhr_feeder_chest`}（方块与它的方块物品同名）· 方块实体类型同名

## 特点简介
方块愚者（`BHR`）模块的**动物自助取食**容器方块：一个 27 格的容器，装进动物能吃的食物后，
附近的动物会**自己走过来**，站在箱子**正前方那一格**，向箱子要一口吃的 —— 效果与玩家手持食物右键喂它**完全一致**。

- **存储**：27 格（与箱子 / 木桶同级），内容随存档保存；破坏方块时**原样吐出**（含被咬剩的堆叠）。
- **朝向**：按熔炉的规则**面朝玩家**放置（水平四向），正前方那一格就是取食位。
- **打开方式**：右键即开，界面是**原版三行箱子界面**（没有自定义面板、没有自定义菜单类型）。
- **没有开盖动画、没有开盖音效**（刻意不做，因此也没有「被打开次数」的计数）。

## 喂食规则
动物满足下面条件才会走过来并被喂：

| 动物状态 | 结果 |
| --- | --- |
| 成年、且不在求偶冷却里 | 进入求偶（**600 tick = 30 秒**，出爱心粒子） |
| 幼崽、且还能长大 | 立即缩短剩余成长时间的 **10%**（与原版喂食同一公式） |
| 成年但在求偶冷却里 / 幼崽已成年 | 不喂，也不会走过来 |

- **一次到站只吃一口**：吃到后本次寻路立刻结束，不会站在原地连吃。
- **冷却**：成年动物的 30 秒冷却由原版求偶计时器提供；幼崽靠「一次一口 + 30~60 秒才会再想起来」限制。
- **认食物靠原版标签**：箱子不维护白名单，直接用该动物自己的 `isFood`（牛吃 `cow_food`、鸡吃 `chicken_food`……）。
  所以**给原版动物加新食物 = 往对应物品标签里加一条**，不需要改代码。
- **一次只服务一只动物**：两只动物同时到，先到的那只吃。箱里没有它能吃的东西时，它根本不会过来。

## 构造
父级：木桶（`minecraft:barrel`）

| 条目   | 值       | 评价                    |
| ---- | ------- | --------------------- |
| 硬度   | 2.5     | 复制木桶，斧类可加速            |
| 爆炸抗性 | 父级      |                       |
| 声音组  | 木头      | `SoundType.WOOD`      |
| 碰撞   | 整格      | 与原版桶一致                |
| 亮度   | 0       |                       |
| 朝向   | 水平四向    | 放置时面朝玩家；结构方块搬运不自动转向（未实现） |

## 红石与自动化
- **比较器读数**：按容器充满度输出 0~15（与箱子 / 木桶 / 漏斗同一套算法，每格按占比求和）。
  所以「箱里快空了」可以用红石看出来。
- **漏斗可以插入与抽出**：本方块就是普通容器，26.2 的漏斗对「有方块实体且实现了容器」的方块
  直接取用，槽位是所有 27 格、方向不限。**不需要**额外实现「可按面抽取」的接口；
  以后若要「顶面只进、侧面只出」那种面级规则，才需要补那三个方法。

## 与「箱子 / 木桶」的差异（刻意的）
- **没有开盖动画、没有开盖音效**：原版箱子/木桶靠「打开次数」驱动盖子动画与音效，本方块全程不做。
- **没有双箱合体**：两个并排的喂食箱子是两个独立容器（原版箱子会合成大箱子）。
