# 超级滑滑冰（方块）
{`rdt_super_lubricent_ice`}
## 特点简介
一种非常滑的冰方块。在其表面不会改变速度，就像该方块没有摩擦力一般。

## 备注
- **「滑行而不改变速度」的重制结论（2026 本轮）**：26.2 的水平衰减是
  `f3 × computeModifiedFriction(0.91, AIR_DRAG_MODIFIER)`，其中
  `computeModifiedFriction(a,b) = clamp(1-(1-a)*b, 0, 1)`。
  要零衰减就需 `f3 = 1/0.91 = 1.0989`（旧代码那个数的来历），但新公式**把结果 clamp 到 1.0**，
  所以方块属性最多只能到 `friction(1.0F)`、每 Tick 仍掉 9% —— 这就是「旧补偿方案失效」的原因。
  故本方块：属性写 `friction(1.0F)`（原版最滑档），零衰减由
  `com.rcdmake.whimsy.mixin.RDT_SuperLubricentIceFrictionMixin` 在那唯一调用点补上（`ordinal = 0`）。
  ⚠️ 该 Mixin **尚未在游戏内验证**，且用 `require = 0` 写成「不命中也不崩」；日志里若出现 Mixin 未命中的提示，
  说明版本结构变了，功能会退回 `friction(1.0F)` 的表现。删除方式：删 Mixin 类 + 两处 JSON 登记。
- 站在本方块上时**起步加速很弱**（`getFrictionInfluencedSpeed` 在 friction > 0.6 时按 `0.216/f³` 缩小输入加速度），
  但滑起来不掉速 —— 这正是「滑行」的手感，与冰的经典表现一致。
- 地图颜色待定（wiki 写「父级*，蓝绿色」），当前沿用蓝冰的地图色。
