# 鲁米诺方块（方块）
该Java类包含3个方块：红色鲁米诺方块{`rdt_luminous_block_red`}、绿色鲁米诺方块{`rdt_luminous_block_green`}、蓝色鲁米诺方块{`rdt_luminous_block_blue`}
## 特点简介
一种视觉上渲染为纯色的方块。

## 渲染
- 忽略任何修改因素，将该方块渲染为纯色（**已实现**）：贴图本身就是单一纯色（红 #FF0000 / 绿 #00FF00 / 蓝 #0000FF，每张图只有一种像素），
  方块侧用 `emissiveRendering(state -> true)` 让它始终满亮度（不吃光照），模型侧用
  `"ambientocclusion": false` + 每面 `"shade": false` 关掉环境光遮蔽与「面朝向明暗」，于是六面颜色完全一致。
  因此模型写成了显式 `elements`（六面照例都带 `cullface`），不再只是 `parent: block/cube_all`。

## 备注
- 亮度按 wiki 保持 **0**（不实际发光）；1.20.4 旧代码里的 `luminance(state -> 1)` 已去掉 ——
  它会让方块真的发出 1 级光，与「不实际发光、仅视觉上发光」矛盾。
- 纯色是「贴图 + 不被光照和明暗修改」得到的，**不需要颜色提供器**（既不用 `BlockColorRegistry`，也不用 `tints`）。
- 三个方块共用同一条属性构造与同一个注册方法，只有贴图不同。
