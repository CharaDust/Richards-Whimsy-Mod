# 通灵木板（方块）
{`rdt_spectre_planks`}
## 特点简介
一种半透明树木的木板方块。**顶面可以站立，按住 Shift 就能从顶面穿下去**；侧面与身位在方块内一律可穿过
（与 [通灵原木](RDT_TreeLogSpectre.md)、[通灵树叶](RDT_TreeLeavesSpectre.md) 同一套碰撞逻辑）。

## 渲染
- 透明状态：依据纹理Alpha通道透明（`rdt/spectre_trsp_planks.png` 整图 **Alpha 恒 195**，属于半透明档；
  隔壁的 `spectre_planks.png` 是 Alpha 恒 255 的不透明版，**不用**）
- 模型 `block/cube_all`，六个面都带 `cullface`
- **物品形式就是方块模型**：原版木板这一类整块方块的物品外观本来就指向 `block/<id>`
  （`items/oak_planks.json` → `minecraft:block/oak_planks`），所以**不进**物品模型例外表 ——
  与通灵树苗（`block/cross` 型植物，物品必须是 2D 精灵）刚好相反
- 26.1 起不再需要手动注册渲染层，半透明档由贴图 Alpha 自动判定

## 改写方法
- **碰撞：顶面可站立 / 按住 Shift 穿过（2026-10 起，与通灵原木、通灵树叶共用同一套实现）**
	- 规则本体在 `RDT_SpectrePassThrough`（三块唯一的手感来源），本方块只填一个参数：
		「父级形状 = `Shapes.block()`」（父级是橡木木板，本来就是整块）
	- 判定式照抄 26.2 原版脚手架 `ScaffoldingBlock.getCollisionShape`
- **位于方块内时减速**（xyz 各乘 0.85）—— 与另两块同值（`RDT_SpectrePassThrough.INSIDE_DRAG`）
- **挡水靠 `forceSolidOn()`**：木板不可含水，属性层的 `noCollision()` 清掉碰撞开关后，
	必须靠它把「概念性固体」钉死为真，否则水流会把木板冲掉（通灵原木踩过这个坑）
	- 与树叶的分工不同：树叶可含水，**不能**加这一条（详见 [通灵树叶](RDT_TreeLeavesSpectre.md)）
- **环境光遮蔽 0.9**（与通灵原木同档）。若不写，兜底形状是整块 → 默认实现会取 0.2F，阴影偏重、
	与「半透明木料」的观感不符
- 不是「改写」但要写在这里：非实体上下文（光照 / 支撑 / 渲染 / 红石 / 寻路）的兜底形状是
	**父级形状 = 整块**，所以本方块在这些方面的行为与原版木板一致。
	**这正是范式 §7 硬约束第 4 条要求的做法**（兜底返回空会让方块被水冲掉、告示牌也贴不上）

## 事件
- 无（纯建筑方块：没有随机刻、没有方块实体、没有交互）

## 方块状态
- **无**（单状态方块，没有 `Property`）
	- 因此它的 `blockstates/rdt_spectre_planks.json` **由 datagen 生成**（`BlockStateGenerator`，
		已在 `collectAll()` 里声明），**不手写** —— 这一点与通灵原木 / 树叶 / 树苗相反（那三块是多状态）
