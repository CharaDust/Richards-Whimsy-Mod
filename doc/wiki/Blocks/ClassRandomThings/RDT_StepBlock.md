# 垫脚方块（方块）
{`rdt_step_block`}
## 特点简介
一种放置后定时自动被破坏的方块。
## 构造
父级：无

| 跳跃乘数    | 默认          |          |

## 渲染
- 透明状态：依据纹理像素点存在性透明

## 改写方法
- 环境光遮蔽设置为0
- 返回透明方块状态
## 事件
- 被放置时：添加一个200Tick的计划刻
- 计划刻被激活时：破坏方块
