# 通灵镜片（方块）
{`rdt_spectre_lens`}
## 特点简介
一种放在信标正上方、像地毯一样的薄层镜片。它把下方信标的效果「搬运」到全维度：每次信标时钟（4 秒）都会读一次下方信标，把效果与强度记进全局记录，并让该维度内所有玩家获得记录里的效果，时长固定 17 秒。

## 渲染
- 透明状态：依据纹理Alpha通道透明
- 模型：1/16 高的薄层（`minecraft:block/thin_block` 家族，与原版地毯同一套几何）

## 改写方法
- 形状：轮廓与碰撞箱改为 1/16 高薄层
- 环境光遮蔽为 0、返回透明方块状态（补回父级玻璃的类行为；`ofFullCopy` 只复制属性，不复制类行为）

## 事件
### 镜片自身
- 被放置时：立即读一次下方信标并写记录，排下 80 tick 计划刻
- 每 80 tick（计划刻）：重排下一拍，并重算本镜片的记录
- 相邻方块变化时：立即重算
- 被拆除时：把该坐标从全局记录里删掉（失效信号）

### 全局（服务端每 80 tick，与信标同拍）
- 校验全部记录：区块未加载 → 保留；已加载但不是镜片 → 删除；下方信标失效或效果改变 → 删除
- 按记录给该维度内所有玩家施加效果，时长固定 17 秒（340 tick）

## 记录结构
```
维度
├─ 效果
│  ├─ I 级 → [镜片坐标…]
│  └─ II 级 → [镜片坐标…]
└─ 效果
   └─ I 级 → [镜片坐标…]
```
- 强度等级：I 级 = amplifier 0；II 级 = amplifier 1（4 级信标且主副效果相同时才会出现）
- 坐标数组本身即去重器：多个镜片同效果不会叠加，施加时按 (效果, 等级) 节点做一次
- 数组空 = 该节点不存在（删除时逐层回收）

## 备注
- 镜片放在信标正上方不会遮挡信标光束：1/16 薄层 + 玻璃属性，光束扫描的 `lightDampening` 判定是 0，信标自身效果照常结算
- 区块未加载时记录保留（查询失败不删）；区块重新加载后 ≤4 秒内镜片会自行修正记录
- 全局记录只在内存中（不随存档保存）；服务器重启后随镜片所在区块的加载自动重建
- **获取方式**：配方与战利品表按全项目约定暂缓，等统一阶段再补
