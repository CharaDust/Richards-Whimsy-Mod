# 固化水方块（方块）
{`wi_static_liquid_water`}
## 特点简介
一种与原版“水”具有相同纹理，但是视为常规完整方块的方块。适合用来整蛊他人。

## 渲染
- 透明状态：依据纹理Alpha通道透明
- 后期上色：和原版“水”同原理（未实现，但破坏的粒子效果正常）

## 改写方法
- 环境光遮蔽设置为0
- 返回透明方块状态
- 两个相同方块连接时，贴合的面不可见（需同时满足：方块类覆写 `skipRendering` + 模型的面写 `cullface`，详见 [客户端渲染接线](../../Misc/客户端渲染接线.md)）
