# 标签（misc）

> 本页收录模组定义的标签与对原版标签的修改，供重制时对照。

## 模组标签
| 标签 | 说明 |
| --- | --- |
| {`richards-whimsy-mod:lgc_vanilla_ore`} | 原版矿物集合标签，用于把原版各类矿石标签并入一个标签 |

## 对原版标签的修改
| 目录/文件 | 说明 |
| --- | --- |
| `data/minecraft/tags/blocks/mineable/axe.json` | 斧可挖掘 |
| `data/minecraft/tags/blocks/mineable/hoe.json` | 锄可挖掘 |
| `data/minecraft/tags/blocks/mineable/shovel.json` | 锹可挖掘 |
| `data/minecraft/tags/blocks/need_diamond_tool.json` | 需要钻石级工具 |
| `data/minecraft/tags/blocks/needs_iron_tool.json` | 需要铁级工具 |
| `data/minecraft/tags/blocks/needs_stone_tool.json` | 需要石级工具 |

## 现状与限制
- 「合适的挖掘工具」与工具等级**只存在于数据包标签**中，方块文档的属性表里长期为空
- 现有写法是**整体替换**原版标签内容，而非追加
- 这些标签的生成同样受 datagen 故障影响，部分为手工编写

## 重制注意
- 26.x 支持在原版标签中追加/移除条目（`fabric:remove`），重制时应改为**追加式**写法，避免覆盖原版标签
- 数据包目录名在 1.21 起已单数化（`tags/blocks` → `tags/block`），重制时需同步
- 工具等级命名建议统一为 `needs_*_tool` 风格
