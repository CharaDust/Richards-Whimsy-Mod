# 文档范式说明（misc）

> 本页固定下列写法，供后续文档保持一致。重制期间新增/修改文档时请遵循。

## 1. 注册名
- 位置：**一级标题正下方**（单方块/单物品类），或**每个名称之后**（复合类）
- 形式：用花括号 + 行内代码包裹，如 `` {`bhr_compost`} ``
- 改名：写成 `` {`旧名`→`新名`} ``
- 格式规范：`模块代号_名称`（`bhr` / `rdt` / `wi` / `dev` / `lgc`）；名称优先取类名
- 矿石命名法：`模块代号_承载方块_矿物质_ore`（范本：`` {`bhr_limestone_oil_ore`} ``）
- 待人工命名：在一级标题下加 `#waiting2check`

## 2. 状态标签
| 标签 | 含义 |
| --- | --- |
| `#deprecated` | 该条目/类将被替换、更名或迁移 |
| `#todo` | 迁移后**需要创建的类**（目标页） |
| `#waiting2check` | 需人工命名（多方块/多物品类） |
| `#mixin` | 该条行为由 Mixin 实现 |

`[!DANGER]` / `[!WARNING]` / `[!FAIL]` 是 Obsidian 风格化提示块，用于视觉强调，不承担语义。
其中 `[!FAIL]` + 明确写出“删除”的页面，表示该条目将被删除（豁免注册名补全）。

## 3. 获取方式（战利品表与合适工具）
方块/物品页统一使用以下骨架；**具体数值留待迁移后统一设定**，此时只保留结构：

```
## 获取方式
### 战利品表
#### 采集
- 挖掘{名称}的合适工具：{待迁移后统一设定}
- {名称}被破坏后掉落：{待迁移后统一设定}
```

- 属性表中的「合适的挖掘工具」一行填 `见「获取方式」`，不再单独留空
- 矿物的「掉落物」同样写 `{待迁移后统一设定}`
- 该范式已在 `BHR_Rocks` / `BHR_Soils` / `BHR_Gems` / `BHR__NormalBlocks` 拆分出的 25 份方块页中落地

## 4. 父级
- 含义即代码中的“复制某方块属性”
- 被复制对象是原版方块 → 写原版中文名（如“石头”“玻璃”）
- 被复制对象是模组方块 → 写模组中文名（如“红壤”）
- 无父级（使用全新属性）→ 写“无”

## 5. 不写的内容
- 不展开代码实现细节（方法名、NBT 键名等），只写**行为**
- 「评价」列为可选补充说明，不强制填写
- 不写“验收方法”字段
