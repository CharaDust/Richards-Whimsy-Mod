# 配方（misc）

> 本页收录自定义配方类型与数据包配方，供重制时对照。

## 自定义配方类型
| 项 | 注册名 | 说明 |
| --- | --- | --- |
| 配方类型 | {`simple_working`} | 简易工作方块专用配方类型 |
| 配方序列化器 | {`simple_working`} | 同名序列化器 |

## 数据包配方（手工 JSON）
| 文件 | 说明 |
| --- | --- |
| `dev_item_to_block.json` | 开发物品 → 方块 |
| `dev_item_to_block_fs_vct_u.json` | 开发物品 → 固定向上方块 |
| `enchant_golden_apple.json` | 附魔金苹果相关 |
| `soill_to_dirt.json` | 土壤 → 泥土 |

## 现状与限制
- **数据生成（datagen）无法自动生成配方**，因此配方全部为手工编写的 JSON
- 自定义配方类型**尚未被任何方块实体查询**；简易工作方块目前使用硬编码的测试配方
- 因此：[DEV_SimpleWorker](../BlockEntities/ClassDEV/DEV_SimpleWorker.md) 的「特点简介」中“可使用已定义的配方”属**目标**而非现状

## 重制注意
- 26.x 中配方序列化器由 `MapCodec` + `StreamCodec` 构成，不再需要内部序列化器实现类；本页两个注册名对应的实现方式需整体重写
- 重制时建议先修复 datagen，再统一生成配方，以替代手工 JSON
