## 26.2 的两处私有 API（用类调整文件放开）
26.2 把下面两处改成了私有，注册自定义界面的模组都得绕过它们：

| 目标 | 为什么要 | 本项目的做法 |
| --- | --- | --- |
| `MenuType.<init>` + `MenuType$MenuSupplier` | 原版只在私有 `register` 里用；`MenuType` 是「打开界面数据包」里写的注册表项 | `richards-whimsy-mod.classtweaker` 里 `accessible` |
| `MenuScreens.register` + `MenuScreens$ScreenConstructor` | 把「菜单类型 → 屏幕类」接起来；Fabric API（`fabric-menu-api-v1`）只提供 `ExtendedMenuType` / `ExtendedMenuProvider`，没有这个入口 | 同上 |

- Fabric 的 `ExtendedMenuType` 也能用，但它把 `create(int, Inventory)` 改成抛异常，
  必须走「打开时附带数据」那条路；本项目的界面不需要附带数据，所以直接用原版 `MenuType`。
- 26.2 的界面渲染换了模型：屏幕重写 `extractBackground(GuiGraphicsExtractor, …)`（背景）
  与 `extractRenderState(…)`（内容）；旧教程里的 `render(GuiGraphics, …)` / `renderBg(…)` 已不存在。
- 原版大箱子屏幕的类名从 `ChestScreen` 改成了 `ContainerScreen`（`net.minecraft.client.gui.screens.inventory`）。
