# 宝石祝福测试棒（物品）
{`richards-whimsy-mod:bhr_gem_bless_test`}
## 特点简介
一件开发期用的物品：用来给别的物品施加 / 清除 [宝石祝福](../Component/ClassBlockHeadsRebon/BHR_GemBlessing.md)。
不是玩法内容，正式版可随时移除 —— 祝福本身（组件、等级计算、tooltip）不依赖本物品。

## 构造
```
普通物品（无特殊构造），默认组件
```
- 注册名 `bhr_gem_bless_test`，创造模式物品栏「方块愚者」最后一项
- 贴图暂用紫锂辉宝石（`textures/item/bhr/gem_amethyst.png`），等有专用贴图再换

## 用法
| 操作 | 效果 |
| ---- | ---- |
| 右键 | 给**副手**物品加上下一种还没加过的祝福，顺序：紫锂辉 → 蓝宝石 → 祖母绿 → 红刚玉 → 宝石钻石 |
| 潜行 + 右键 | 清空副手物品上的全部祝福 |

- 作用在副手：本物品拿在主手时才谈得上「用它去点」，而祝福要给的是工具，主手位置已经被测试棒占着
- 副手为空时会在聊天框明确提示，不做「就近挑一件」这种猜谜行为
- 每次操作都会把当前生效的祝福一并播报出来，便于对照组件内容

## 改写方法
改动「施加途径」（比如改成右键宝石方块）只需替换本类，`BHR_GemBlessing.set/clear` 的接口不变。
