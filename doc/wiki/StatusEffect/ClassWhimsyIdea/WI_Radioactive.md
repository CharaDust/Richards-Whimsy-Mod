# 电离辐射（状态效果）
{`wi_radioactive`}
## 特点简介
一种能减少生命值上限，并随时间减少生命值，可反向传染的负面状态效果。其他生物通过攻击拥有该效果的生物实现传染

## 构造

| 条目   | 值          | 评价  |
| ---- | ---------- | --- |
| 类型   | HARMFUL    |     |
| 粒子颜色 | `0xF3A923` |     |

## 数值
- 按照{等级}，每{伤害间隔}对拥有此状态效果的目标造成{伤害值}火焰伤害，并按百分比减少{生命值上限减少}的生命值上限

| 等级  | 伤害间隔     | 伤害值 | 生命值上限减少 |
| --- | -------- | --- | ------- |
| I   | 每100Tick | 2   | 15%     |
| II  | 每80Tick  | 2   | 30%     |
| III | 每60Tick  | 2   | 45%     |
| IV  | 每40Tick  | 2   | 60%     |
| V   | 每20Tick  | 2   | 60%     |
| $x$ | 每20Tick  | 2   | 60%     |

## 事件主持器
- 类名：`WI_RadioactiveAttackEventHandler`
	- 描述：当被攻击者拥有 II 级及以上的状态效果受到攻击时，对攻击者施加被攻击者 ${等级}-1$ 等级， $剩余时间 \div 2$ 时间的同名效果。
		- （未实现）当受到非近战攻击时，产生 ${等级}-1$ 等级， $剩余时间 \div 2$ 时间的同名效果云。
