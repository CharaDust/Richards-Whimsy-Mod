# 电离辐射（状态效果）
{`wi_radioactive`}
## 特点简介
一种能减少生命值上限，并随时间减少生命值，可反向传染的负面状态效果。其他生物通过攻击拥有该效果的生物实现传染

## 构造

| 条目   | 值          | 评价  |
| ---- | ---------- | --- |
| 类型   | HARMFUL    |     |
| 粒子颜色 | `0xF3A923` |     |

## 数值
- 按照{等级}，每{伤害间隔}对拥有此状态效果的目标造成{伤害值}火焰伤害，并按百分比减少{生命值上限减少}的生命值上限

| 等级  | 伤害间隔     | 伤害值 | 生命值上限减少 |
| --- | -------- | --- | ------- |
| I   | 每100Tick | 2   | 15%     |
| II  | 每80Tick  | 2   | 30%     |
| III | 每60Tick  | 2   | 45%     |
| IV  | 每40Tick  | 2   | 60%     |
| V   | 每20Tick  | 2   | 60%     |
| $x$ | 每20Tick  | 2   | 60%     |

- **无生命值下限**：电离辐射会正常把目标扣死（与「生物毒性」不同 —— 后者有 6 点保底）。
- **死亡信息**：伤害类型为火焰伤害，因此被辐射致死的提示与原版「被烧死」一致。

## 事件主持器
- 类名：`WI_RadioactiveAttackHandler`
	- 描述：当被攻击者拥有 II 级及以上的状态效果受到伤害时，按**伤害类型**分两条路传播：
		- **近战**：对攻击者施加被攻击者 ${等级}-1$ 等级， $剩余时间 \div 2$ 时间的同名效果。
		- **非近战**（箭、火球、爆炸、火焰、魔法、无源伤害等）：在被攻击者所在位置生成一团药水云（半径 5 格、持续 20Tick），云携带 ${等级}-1$ 等级、 $剩余时间 \div 2$ 时间的同名效果，由云感染范围内碰到的生物。
	- **近战判定口径**：伤害的「直接来源」与「造成伤害者」为同一实体，且不属于爆炸、投射物标签。即玩家挥剑、生物近身攻击算近战；箭/火球（直接来源是投射物）、爆炸、以及摔落等无来源伤害都算非近战。
- 触发时机：效果被挂上时播放注册名为 `wi_radioactive_applied` 的声音。
