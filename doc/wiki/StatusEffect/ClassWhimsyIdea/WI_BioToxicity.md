# 生物毒性（状态效果）
{`wi_bio_toxicity`}
## 特点简介
一种随时间减少生命值，可正向传染的负面状态效果。拥有该效果的生物通过攻击其他生物实现传染

## 构造

| 条目   | 值          | 评价  |
| ---- | ---------- | --- |
| 类型   | HARMFUL    |     |
| 粒子颜色 | `0x007951` |     |

## 数值
- 按照{等级}，每{伤害间隔}对拥有此状态效果的目标造成{伤害值}魔法伤害
- **生命值下限：本效果造成的伤害不会把目标打到 6 点生命值以下**（即保留 3 颗心）。目标生命值 ≤ 6 时停止扣血；效果本身仍在、传染仍在，只是不再造成伤害。

| 等级  | 伤害间隔    | 伤害值 |
| --- | ------- | --- |
| I   | 每80Tick | 2   |
| II  | 每60Tick | 2   |
| III | 每40Tick | 2   |
| IV  | 每20Tick | 2   |
| V   | 每20Tick | 2   |
| $x$ | 每20Tick | 2   |

### 生命值下限（6 点 = 3 颗心）的界面表现
- 拥有该效果时，生命条按原版中毒规则整体变为绿色心。
- **最左侧 3 颗心保持红色（默认色）**，作为「毒性打不穿这 3 颗心」的视觉标识。
- 伤害吸收的黄色心不受此规则影响，仍按原版显示为黄色。

## 事件主持器
- 类名：`WI_ToxicAttackEventHandler`
	- 描述：当攻击者拥有状态效果攻击目标时，对目标施加攻击者 ${等级}-1$ 等级， $剩余时间 \div 2$ 时间的同名效果。
		- 等级 I 及以上均可传染：等级 I 时 ${等级}-1 = 0$，即以 0 级（中毒 I）传染给目标。
	- 以下生物免疫该效果（**准确说：免疫伤害与被传染，但不是免疫效果本身**）：
		- 铁傀儡、雪傀儡、凋灵、骷髅、凋零骷髅、骷髅马、流浪者、烈焰人、岩浆怪（新）、史莱姆（新）
		- 名单里的生物的行为：
			- ✅ **可以**带上生物毒性 —— 用喷溅/滞留药水或 `/effect` 指令都能挂上；
			- ❌ **不受到**该效果造成的伤害（挂着也不掉血）；
			- ❌ **不会被**其他生物的生物毒性传染（传染对他无效）；
			- ✅ **仍然能**把身上的生物毒性传染给别的生物（自身作为传染源时不受名单限制）。
		- 一句话概括：免疫是「不掉血 + 不被传」，**不是**「挂不上」。
- 触发时机：效果被挂上时播放注册名为 `wi_bio_toxicity_applied` 的声音。
