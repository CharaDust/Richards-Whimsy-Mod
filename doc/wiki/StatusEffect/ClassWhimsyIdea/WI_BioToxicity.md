# 生物毒性（状态效果）
{`wi_bio_toxicity`}
## 特点简介
一种随时间减少生命值，可正向传染的负面状态效果。拥有该效果的生物通过攻击其他生物实现传染

## 构造

| 条目   | 值          | 评价  |
| ---- | ---------- | --- |
| 类型   | HARMFUL    |     |
| 粒子颜色 | `0x007951` |     |

## 数值
- 按照{等级}，每{伤害间隔}对拥有此状态效果的目标造成{伤害值}魔法伤害

| 等级  | 伤害间隔    | 伤害值 |
| --- | ------- | --- |
| I   | 每80Tick | 2   |
| II  | 每60Tick | 2   |
| III | 每40Tick | 2   |
| IV  | 每20Tick | 2   |
| V   | 每20Tick | 2   |
| $x$ | 每20Tick | 2   |

## 事件主持器
- 类名：`WI_ToxicAttackEventHandler`
	- 描述：当攻击者拥有 II 级及以上的状态效果攻击目标时，对目标施加攻击者 ${等级}-1$ 等级， $剩余时间 \div 2$ 时间的同名效果。
	- 以下生物免疫该效果：
		- 铁傀儡、雪傀儡、凋灵、骷髅、凋零骷髅、骷髅马、流浪者、烈焰人、岩浆怪（新）、史莱姆（新）
