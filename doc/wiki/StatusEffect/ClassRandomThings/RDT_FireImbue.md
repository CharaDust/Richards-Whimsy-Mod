# 火焰灌注（状态效果）
{`rdt_fire_imbue`}
## 特点简介
一种能使攻击附带火焰的正面状态效果。拥有该效果的生物通过攻击其他生物时会使其进入燃烧状态（类似于火焰附加、火矢）

## 构造

| 条目   | 值          | 评价  |
| ---- | ---------- | --- |
| 类型   | BENEFICIAL |     |
| 粒子颜色 | `0xF68127` |     |

## 数值
- 按照{等级}，对攻击目标施加{着火时间}的燃烧效果

| 等级  | 着火时间               |
| --- | ------------------ |
| I   | 100Tick            |
| II  | 200Tick            |
| III | 300Tick            |
| IV  | 400Tick            |
| V   | 500Tick            |
| $x$ | $x\times 100$ Tick |
