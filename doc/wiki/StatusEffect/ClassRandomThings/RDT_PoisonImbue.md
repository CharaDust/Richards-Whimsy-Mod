# 毒性灌注（状态效果）
{`rdt_poison_imbue`}
## 特点简介
一种能使攻击附带中毒的正面状态效果。拥有该效果的生物通过攻击其他生物时会对其施加中毒效果

## 构造

| 条目   | 值          | 评价  |
| ---- | ---------- | --- |
| 类型   | BENEFICIAL |     |
| 粒子颜色 | `0x41DD53` |     |

## 数值
- 按照{等级}，对攻击目标施加{着火时间}的燃烧效果

| 等级  | 中毒时间    | 中毒等级 |
| --- | ------- | ---- |
| I   | 450Tick | I    |
| II  | 900Tick | I    |
| III | 900Tick | II   |
| IV  | 900Tick | II   |
| V   | 900Tick | II   |
| $x$ | 900Tick | II   |
