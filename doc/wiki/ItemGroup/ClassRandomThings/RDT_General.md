# 随意物件物品栏（创造模式物品栏）
{`rdt_general`}
## 特点简介
随意物件（RDT）分支的创造模式物品栏页。

## 构造
| 条目   | 值                      |
| ---- | ---------------------- |
| 标题语言键 | `itemGroup.rdt_general` |
| 图标   | 皮革帽（原版物品） |
| 排序   | 按下方「包含物品」的添加顺序 |

## 包含物品
- 超级滑滑冰、青金石玻璃、石英玻璃
- 垫脚方块
- 通灵原木
- 红色/绿色/蓝色鲁米诺方块
