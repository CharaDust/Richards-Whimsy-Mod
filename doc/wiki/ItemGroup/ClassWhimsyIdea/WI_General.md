# 奇思妙想物品栏（创造模式物品栏）
## 特点简介
奇思妙想（WI）分支的创造模式物品栏。本类包含**两个**物品栏页，故加 `#waiting2check` 待手动命名。

## 构造
### 物品栏一：方块
| 条目    | 值                                         |
| ----- | ----------------------------------------- |
| 注册名   | {`whimsy_group_block` → `wi_group_block`} |
| 标题语言键 | `itemGroup.wi_group_block`                |
| 图标    | 包装木材                                      |
| 包含物品  | 固石、包装木材、气凝胶、糖块、糖玻璃、固化水方块                  |

### 物品栏二：物品（尚未实现，计划见下）
| 条目    | 值                                           |
| ----- | ------------------------------------------- |
| 注册名   | {`whimsy_group_item` → `wi_group_item`}     |
| 标题语言键 | `itemGroup.wi_group_item`                   |
| 图标    | 钻石（原版物品）                                    |
| 包含物品  | 紫锂辉、蓝宝石、祖母绿、红刚玉、宝石钻石、结晶蜜、探矿器、书（原版）、渲染器测试物品 |

> 上表为迁移前的原始规划。其中宝石属 `BHR`、结晶蜜属 `LGC`、渲染器测试物品已随 `WI_ShaderDevRed` 删除，
> 所以这一页实际只剩「探矿器 + 原版书」等内容，等 WI 物品阶段再定稿并注册。

## 现状与限制
- 方块页已于 26.2 方块重制阶段实现（注册名 `wi_group_block`，标题键 `itemGroup.wi_group_block`）。
- 物品页 `wi_group_item` **尚未注册**：它列的紫锂辉、蓝宝石、祖母绿、红刚玉、宝石钻石属于 `BHR` 模块，结晶蜜属 `LGC`，探矿器属 WI 的物品阶段，渲染器测试物品已删除。空物品栏页不该出现在物品栏里，故留到 WI 物品阶段与探矿器一起注册。

## 重制注意
- 原「包含物品」表里的**板岩**已改归 `BHR`（见 [模板遗留方块](../../Misc/模板遗留方块.md)），不计入本页；同一张表漏掉了本就属于 WI 的**糖玻璃**与**固化水方块**，现已补入上表（顺序：wiki 原有顺序打头，两个漏项按迁入顺序补在末尾）。
- 两个标签页的注册名均缺模块前缀（`whimsy_group_*` → `wi_group_*`），已按 `模块代号_名称` 改名。
- 一个类内注册多个物品栏页是本类的特殊性；实现上把注册抽成一个私有方法，每页调用一次（见 `WI_CreativeTabs`，目前只有方块页在调用）。
